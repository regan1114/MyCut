首頁操作涵蓋不自動建立空白專案、選比例和 fps 建立、搜尋、改名、複製、回收及還原、專案檔匯入、從中文檔名的音訊建立專案。字幕操作使用真正的音訊上傳及本機引擎，校對後加入獨立字幕軌、復原／重做、儲存再開啟、歌詞模式與 LRC 下載。

辨識詳見 `speech-test-result.json`。一小時音訊測試在片頭、片尾放原創語音，中間是靜音，驗證分段跳讀、靜音略過、時間偏移及已完成區段恢復；**不代表一小時連續談話、真實歌曲或密集伴奏的準確率已驗證**。歌詞測試為合成歌唱，未驗證專業人聲分離。

逐字高亮與聲學對齊見 `karaoke-test-result.json`。DTW 字詞時間是模型估計，沒有人工標註資料集的誤差評分。中文模型 token 可能包含數個字，編輯器可按字重新分段並手動校時。沒有有效字詞時間的字幕不會自動開啟高亮。原生 Canvas 已顯式設定可變字型的 wght=400，避免與瀏覽器字重不同。

頻譜長片資料驗證見 `spectrum-hour-test-result.json`，重現命令 `node --import tsx scripts/verify-spectrum-hour.ts`；測試的是連續純音分析與快取大小，不是整小時連續視訊的同步量測。

操作測試涵蓋新增文字、粉圓字型、複製、刪除、復原、重做、滑鼠拉邊裁切、一小時時間軸全片檢視、8 軌捲動對齊、20 款字型清單、匯出設定視窗、重新載入後的自動儲存、播放快捷鍵。

一小時測試共 364 個分段；詳細輸出與 Node 程序記憶體取樣見 `hour-test-result.json`。此結果只驗證低解析度時間準確性與分段流程，不代表一小時 4K 或複雜專案已完成壓力測試。未量測完整 FFmpeg / GPU / Electron 的總記憶體。

尚未驗證實體麥克風裝置、Apple Silicon、VideoToolbox 在不同 Mac 型號的差異、大量不同編碼真實素材、HDR、正式簽章與公證。

特效測試詳見 `effects-test-result.json`。共用繪圖單元測試涵蓋每一種特效在一小時位置的可重現性、舊專案預設關閉、JSON 往返及音軌裁切／變速／音量／靜音。瀏覽器 GPU／CPU 畫布路徑有最多 4/255 的通道取整容差；粒子位置不隨倒帶重置。

美術縮圖驗證見 `artwork-test-result.json`。新版另通過兩項既有特效操作測試，涵蓋疊加、倒帶、復原、儲存、頻譜及靜音連動；本次只更新素材庫插畫和卡片樣式，未重新執行影片匯出壓力測試。美術總覽見 `artwork-effects.png`、`artwork-transitions.png`、`artwork-filters.png`；封裝介面截圖見 `effects.png`、`transitions.png`、`filters.png`。

特效套用整個合成畫面，並未匯入 LyricFlow 的歌曲處理、場景生成或其字型資產。精靈粒子使用既有的 OFL 思源黑體 TC。節奏觸發是音量突增偵測，未驗證 BPM／拍號追蹤。

帶特效的一小時成品詳見 `effects-hour-test-result.json`。測試包含櫻花、雨絲、精靈粒子、螢火蟲、飄雪、懷舊濾鏡和暗角。此為 320×180 的長時間串流與接縫驗證，尚未進行一小時 1080p／4K 壓力測試；記憶體取樣不包含 FFmpeg 或 Electron。

新增效果的一小時成品詳見 `expanded-hour-test-result.json`，使用 `npm run test:expanded:hour` 重現。包含音樂頻譜、柔光、掃光、落葉、蒲公英、餘燼、星空、VHS、波紋、萬花筒、鏡像與雨滴玻璃；短音訊及歌詞放在 0、1799、3598 秒。這是完整時長的特效串流驗證，並非一小時連續歌詞或複雜原始影片解碼的性能基準。
