MyCut 0.6.11 — Mac / Windows

Windows 11（Intel / AMD x64）：
  安裝：MyCut-0.6.11-Windows-x64-Setup.exe
  免安裝：完整解壓縮 MyCut-0.6.11-Windows-x64.zip，再開啟 MyCut.exe。
  請保留整個資料夾，不要只複製 MyCut.exe。

macOS 14 或更新版本：
  Intel：解壓縮 MyCut-0.6.11-macOS-x64.zip，再開啟 MyCut.app。
  Apple Silicon（M 系列）：使用 MyCut-0.6.11-macOS-arm64.zip。

內含 40 款字型、40 種特效、53 張示意美術、FFmpeg 和離線字幕／歌詞模型。
不必另裝 Node、C++ 執行階段或下載語音模型。x64 語音引擎需要 AVX2。

0.6.11 新增 12 種特效：
  泡泡、漂浮愛心、蝴蝶、彩色紙花、流動絲帶、晨光射線、十字星芒、
  底片顆粒、像素風、漫畫網點、電影黑邊、節奏放射線。
  左側「特效」選擇；右側調整屬性，支援全片與時間軸時段特效。

0.6.10 左側功能、右側屬性：
  左側新增／匯入／辨識／批次操作與選擇特效；右側調整內容與參數。
  全片特效參數移右側；分離音訊在左側音訊，所選歌詞 LRC 匯出在左側字幕。
  移除重複文字樣式入口；音量只在音訊屬性，變形只在基本／文字屬性。

0.6.9 字幕屬性簡化：
  右側「字幕」在前、「文字」在後，字幕只保留搜尋與清單。
  選取字幕後切換「文字」編輯；返回清單保留搜尋與頁次。
  歌詞校時移到「文字」，新增／辨識／批次操作仍在左側功能區。

0.6.8 播放與字幕優化：
  文字預覽重用有上限的畫布，字型依目前畫面載入。
  直式與方形預覽也限制為最高 540 像素高，保留畫面比例。
  點選字幕搜尋結果會保留搜尋，清除按鈕可回到全部字幕。
  修正標記點選，以及取消拖曳或離開編輯器後的手勢清理。

0.6.7 面板與字幕：
  拖曳播放器左右分隔線可調整三個區域，按兩下重設該側。
  最小寬度：功能區 220、播放器 400、屬性區 240 像素。
  選取文字 → 右側「字幕」，可搜尋、條列與定位全部文字。
  0.6.9 起編輯、卡拉 OK 與逐字校時統一在「文字」分頁；時間軸顯示內容，空白則標示空白文字。

0.6.6 文字與字型：
  新片段接到同軌末端；拖曳、修剪與複製會避開同軌內容。
  選取文字 → 右側文字內容 → 字型，直接以字型名稱預覽。
  點名稱套用到目前文字，星號加入最愛；左側獨立字型入口已移除。

0.6.5 精簡介面：
  首頁直接管理專案，左側使用圖示，滑鼠停留會顯示功能名稱。
  特效參數自 0.6.10 起放在右側屬性區；群組與連動工具依選取內容顯示。
  Tab 聚焦可顯示提示，Esc 關閉提示；介面維持黑灰白配色。

0.6.4 字型與我的最愛：
  字型選單有 40 款免費商用字型（10 款繁中、30 款英文）。
  勾選我的最愛，列表中第一個最愛就是新增文字與字幕的預設字型。
  初次或全部取消時使用第一款「思源黑體 TC」，重啟會保留設定。

0.6.3 關閉編輯器：
  Mac 紅色關閉鈕／Windows X：先儲存，再返回檔案管理。
  儲存失敗會留在編輯畫面；匯出與辨識工作繼續執行。

0.6.2 一鍵建立專案：
  點「建立新專案」直接進入編輯器；未命名專案、16:9、1920 × 1080、30 fps。

0.6.1 介面：
  全面改為黑灰＋白色，含首頁、編輯器、字幕和匯出視窗。

0.6.0 新增：
  專案名稱 → 打包完整專案：產生 .mycutpack，包含使用到的原始素材。
  目的電腦從「開啟專案檔」還原，不需保留原始檔案位置。
  時間軸：框選、群組、音畫連動；Shift / Command / Ctrl 點選增減。
  特效 → 時段特效：指定時段、淡入淡出、強度關鍵影格。
  字幕 → 字幕批次編輯：搜尋取代、標點、換行、樣式與重疊提醒。

JSON 專案檔仍只有剪輯設定，搬移素材請使用 .mycutpack。
專案包不包含代理檔、匯出成品或辨識工作紀錄；取消後需重新打包。
