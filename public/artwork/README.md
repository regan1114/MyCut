# MyCut library illustrations

53 original SVG illustrations made for this workspace: 40 effects, 5 transitions, and 8 color presets. They use editable vector paths, local gradients, and soft lighting; no stock images, external fonts, network requests, or embedded bitmap assets.

The artwork illustrates each tool's purpose. It is used only on library cards; project rendering and exported videos use the existing effect and transition implementations.

Regenerate with `npm run art:build`. The editable source is `scripts/generate-library-art.ts`. Open `gallery.html` to review the full collection. The filter illustrations share one composition so their color differences can be compared.
